Traffic period

Daily buckets and the monthly reset boundary use this zone. Reset happens at 00:00 in this zone.

Data packages

Extra data on top of the monthly quota (promotions, add-ons). A package is always used up before the base quota. It refills with the billing period or on its own day of the month. A negative size is a deduction from the base quota. Dates use the reset time zone.

Adjust used traffic

For when the vendor resets or corrects your usage. Recorded traffic, charts and history are never changed: each adjustment is kept in the log below and can be removed again.
Applies from now. Data that is given back goes to the base quota first, then to data packages; an increase is used like traffic (packages first).

Data retention (all servers)

How long each kind of data is kept; 0 = forever. Applies within ~5 minutes. Lowering a value permanently deletes older rows. Rough cost: 1-min data ≈ 43 MB per port/host per year; 1-hour ≈ 0.7 MB; daily ≈ 0.03 MB.

Dashboard password

Backup & migration

Export covers all servers: traffic history, per-server settings (including data packages and adjustments) and registered node configs. Password, secret and SSH keys are not included. Import merges — matching servers/buckets are overwritten by the file, everything else is kept.
